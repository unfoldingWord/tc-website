Create a Bible project

Shippedalpha.1

A Bible project is one translation in one language and one text direction. Name it, give the language, choose the direction, and add books next.

Where in the app: Home › + Add a project › New Bible

What it is

The New Bible dialog creates a new, empty Bible translation project on your computer. The subtitle says it well: "You'll add books next. Everything here can be changed later."

The fields are:

  • Bible name — for example "Kanuri Bible". The first letters and digits of the name also name the project folder.
  • Language name and Code — the language you translate into, for example "Kanuri" and knc (the code for Central Kanuri).
  • Text direction — Left to right or Right to left.
  • Checking language — the gateway language your team checks and aligns against. English ships with the app and has the complete set of book packages, so it is preselected and has a RECOMMENDED badge. Under it: "unfoldingWord · ULT + UST, notes, words — installed with the app". The English texts and helps that come with this build are the v91 releases, so a new project needs no download to start.
  • Script font — the font your translation is shown in. It starts on "Noto Sans (default)". The other choices are Charis SIL, Scheherazade New (Arabic script), Awami Nastaliq (Nastaliq) and Padauk (Myanmar).
  • Versification (folded away) — the verse numbering scheme. Opened, the list is rso, vul, rsc, lxx, eng (default), and org. eng (default) is selected. Under the list: "Most projects keep the default." No other scheme was chosen.

When to use it

When you start translating into a new language, or want a separate practice project.

Step by step

  1. On Home, click + Add a project.
  2. In the Add a project dialog, click the first card, New Bible. The New Bible dialog opens in its place.
  3. Type a Bible name, for example Help Demo Titus.
  4. Type the Language name and the language Code, for example Kanuri and knc.
  5. Under Text direction, click Left to right or Right to left.
  6. Leave Checking language on English (it is already selected).
  7. Optional: choose a Script font, or open Versification to pick another numbering scheme.
  8. Click Create Bible →.
  9. The Add a book dialog opens straight away. Continue with Add a book. The first book you add opens in Understand.

What you should see

  • The New Bible dialog shows Bible name, Language name, Code, Text direction, Checking language (English, Recommended) and Script font.
  • After Create Bible → the Add a book dialog opens straight away.
  • The new project appears on Home.

Tips

  • The name must contain at least one Latin letter or digit, because it names the project folder. If a project folder with that name already exists, tC4 tells you ("A project folder named … already exists") — choose another name.
  • Keyboard: in the Add a project dialog, press Tab until the New Bible card has a blue ring, then press Enter or Space. Esc closes the dialog.
  • If you close the dialog without creating (with Cancel or the round × at the top right), nothing is saved.
  • The New Bible dialog has no back button. To choose another kind of project, click Cancel, then + Add a project again. It opens on the three cards.
  • On a small screen the dialog may not fit. Scroll inside it to reach the top fields or the Create Bible → button.
  • Known issue: Some language codes are refused, even ones that look right. On an earlier build, kau (Kanuri as a whole) was refused with "Language code 'kau' is not custom (no 'x-') but has not been found in the BCP47 lookup table", even though the Code field shows "e.g. kau" as its example (screenshot 4). On this build, typing kau and leaving the field did not show that warning. Use the code for your specific language instead, such as knc for Central Kanuri.
  • Known issue: If you start typing the moment you click into a field, the first letters can be lost. Wait a moment before you type, and check the name before you create the project.
  • You can change the text direction and script font later in Project settings.

Known limits

  • The project name, language name and code cannot be changed after creation yet ("Renaming arrives with a later increment.").
  • Only English is offered as the checking language when you create a project. You can change it later in Project settings if another language's notes are installed. See Change the checking language.
  • Whole books only. "Passage sets come later."
