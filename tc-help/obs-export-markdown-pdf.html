Export stories as PDF or Markdown

Shippedrc.1

Save a print-ready PDF of the stories, a Story Markdown zip, or both alongside Scripture Burrito — from the same Export menu as Bible.

Where in the app: Open a story › Check › Community Checking › Open → › Export

What it is

From Community Checking on an Open Bible Stories project, Export offers three ways to take the stories out of the project: a dated PDF, a Story Markdown zip of the fifty story files, and a Scripture Burrito zip of the whole project.

When to use it

  • PDF — a printable reading copy for reviewers, with or without pictures.
  • Story Markdown — the story Markdown files for other OBS tools.
  • Scripture Burrito — a full project zip to import elsewhere (see Export a project as a Scripture Burrito).

Step by step

  1. Open a story and click Check. If the last checking tool opens instead of the list, click ← All checking tools.
  2. On Community Checking, click Open →.
  3. Optional: set Page setup (Pictures, Layout).
  4. Click Export, then the format you want.
  5. A save window opens with a suggested file name. Keep it or type another, then save.
  6. When the file is saved, the panel shows "Saved <file name>". Close it with its ✕.

What you should see

  • The Export menu lists Export PDF, Story Markdown (.zip) and Scripture Burrito (.zip).
  • Story Markdown (.zip) shows Saved Sample Stories-stories-2026-10-05.zip; Export PDF shows Saved Sample Stories-2026-10-05.pdf; Scripture Burrito (.zip) shows Saved Sample Stories-2026-10-05.zip.
  • The message appears only after the file is saved. Cancel shows no message.

Screenshots

Tips

  • Undrafted frames are not each given a picture. Incomplete draft. says the export shows each run of undrafted frames or stories as one line, without pictures. For story 1 with frames 1–2 drafted, the PDF had both pictures and one line "[ frames 3–16 not yet drafted ]".
  • To save a second PDF with another layout (for example Pictures wrapped), change the layout, export again, and type a new name in the save window, such as Sample Stories-wrapped.pdf.
  • If nothing is drafted, draft at least one frame (or the title) before exporting a PDF.
  • On Linux, the save window is the system file window. Its title bar shows a long "blob:http://127.0.0.1…" address; that is normal. It opens in your Downloads folder, with the suggested name selected in the Name field. On this build its Save and Cancel buttons were above the visible part of the window: press Enter to save, or Esc to cancel.
  • Cancel the save window: no success toast. A failed PDF shows a red Report and leaves the project unchanged.

Known limits

  • The story PDF is A4 only, and its first page has only the title; the frames start on page 2.
  • Export PDF with Pictures on worked on this packaged Linux build. An older build failed with "Printing failed"; if you see "The app could not print the PDF with its pictures…", turn Pictures off and export again.
  • The PDF needs the desktop app (not offered in a plain browser).
