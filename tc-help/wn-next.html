Since alpha.7 — export, import, share and more (not yet released)

Newer work in the build this help describes. Export, import, Share to Door43 (Increment 8.5), scripture-text upgrades and more — retested on 2026-09-29 for epics #372, #369 and #370.

Note: This work is now released in v4.0.0-rc.1 (Oct 2, 2026). See What's new in 4.0 rc.1 (Increment 8) for the current description. This page is kept as the record of the 2026-09-29 retest.

What arrived

  • Export from Community Checking: PDF, USFM, Scripture Burrito; OBS Story Markdown and Burrito (OBS export).
  • Import: Import a project from translationCore 3, USFM or a Scripture Burrito (always a new project).
  • Share to Door43 (Increment 8.5): Share to Door43 — Sign in, Stay signed in, first share and Upload changes.
  • Update scripture texts and Update pinned helps via Project settings › Manage source texts.
  • Page setup, Saved toast, crash recovery, Align word-bank keep, and the single + Add a project button on Home.
