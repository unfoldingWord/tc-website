Write a check comment

Shippedalpha.6

Add a note to a check item about what you decided or what to ask your team.

Where in the app: Inside a checking tool › ✎ Add a comment

What it is

A check comment is a short note attached to one check item.

When to use it

To record the reason for a decision, or a question for a consultant.

Step by step

  1. In a checking tool, click Add a comment.
  2. The box is titled My comment on this check. Its hint is "Say what you decided, or what to ask your team about this check." While it is open, the button changes to Hide comment.
  3. Done and Delete comment are in the box. Neither was clicked on this run, and nothing was typed.
  4. Hide comment closed the box. The button went back to Add a comment, and the Commented count stayed at 0.

What you should see

  • A box titled My comment on this check opens with the hint "Say what you decided, or what to ask your team about this check."
  • While the box is open the button says Hide comment. Done was not clicked, so Comment · written was not seen, and Commented stayed at 0.

Tips

  • Check comments can be deleted. User comments in Understand cannot. See Write a user comment.
