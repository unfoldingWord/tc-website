Update scripture texts

Shippednew since alpha.7

Move the project to a newer release of the Greek or Hebrew text, or of the gateway Bible.

Where in the app: Home › project card › Settings › Manage source texts → › Pinned resources › Check for updates › Scripture texts

What it is

New since alpha.7. Besides the helps, you can update the scripture texts the project is pinned to.

Step by step

  1. On Home, click Settings on the project card, then Manage source texts →. The project opens, with Get source texts on top.
  2. Go online if needed, then in Pinned resources click Check for updates (click Continue if "Use the internet?" appears).
  3. Look under Scripture texts. Each text with a newer release has its own row, for example Gateway Bible en_ult v89 → v91 · 2026-09-26. If everything is current, it says ✓ Every scripture text is up to date.
  4. Click Upgrade on a row.
  5. Read the confirmation and confirm.

What you should see

  • Scripture texts lists the Original-language text and the Gateway Bible.
  • If all are current: ✓ Every scripture text is up to date. Otherwise each row has Upgrade.
  • Upgrading the original text warns "The alignments of {n} verse(s) will be marked invalid."
  • An Original-language text row appears only for a text that one of the project's books needs (Hebrew for an Old Testament book, Greek for a New Testament book), and only when the project pins an older release.

Screenshots

Tips

  • Upgrading the gateway Bible changes nothing in your work: "No alignment and no check decision will change. The source pane will show the new text."
  • Upgrading the original-language text keeps every alignment, but marks the affected ones invalid so you check them again.
  • Which original-language text is offered: only the one your books need. A project with only New Testament books (for example Titus) is never offered the Hebrew text (hbo_uhb), even if it pins an old one. A project with an Old Testament book gets the Hebrew row when its pin is older: "Equipo Ejemplo — Tito y Jonás" (Jonah and Titus, pinned hbo_uhb v2.1.30) showed Original-language text hbo_uhb v2.1.30 → v3.0.0 · 2026-08-14.
  • A new project made with build 79d3017 already uses the texts that come with the app (for example en_ult and en_ust v91), so it says ✓ Every scripture text is up to date.

Known limits

  • Needs internet.
  • A text with no newer release gets no row. In these tests no Greek (el-x-koine_ugnt) row appeared.
  • Save any open alignment edit first: "an alignment edit is not saved. Save it, then try again."
