Understand, Translate and Check — the three modes

Shippedalpha.4

Every open project has three modes. Understand the passage, Translate it, then Check it — in any order.

Where in the app: Top bar, centre — the Understand · Translate · Check switch (shown while a project is open)

What it is

When a project is open, the top bar shows a three-way switch:

  • Understand — read the source passage with its translation notes, word links and questions, and write your own comments. See Read a passage before you translate.
  • Translate — draft your translation beside the source texts. See The Translate screen.
  • Check — check your draft with Translation Notes and Translation Words, align words, and preview the book in Community Checking. See Choose a checking tool.

Open Bible Stories projects have the same three modes.

A book or story you open for the first time starts in Understand, so you read before you draft. After that, tC4 opens it in the mode you used last.

The top bar also shows the project name (click it to go back to Home), the save indicator (Saved or Unsaved changes) and the Door43 account icon. Project settings are not in the top bar; they open from the project's card on Home.

When to use it

Any time. The order is up to you: many teams read in Understand first, draft in Translate, then check.

Step by step

  1. Open a project book (or story) from Home.
  2. Click Understand, Translate or Check in the top bar.
  3. The screen changes; your place in the book stays the same.

What you should see

  • The switch shows three choices; the selected one is filled.
  • Changing mode keeps the same book and chapter (or the same story).
  • A new book, a new story project, or an imported book with no remembered place opens in Understand.
  • The top bar shows no Project settings button and no server name in any mode. At the right there are only the save indicator and the account icon.

Screenshots

Tips

  • Changing mode saves a checkpoint of your work if anything changed (see Saving and checkpoints).
  • tC4 remembers the last mode you used. The Resume banner on Home takes you back to it, and so does the book tile.
  • What changed in Increment 8: a new book used to open in Translate. It now opens in Understand (issue #507). The "Internet" or "Local" status left the top bar; the account icon replaced it.
  • When you click Check, tC4 goes back to the checking tool you used last, not the list of tools. To pick another tool, click ← All checking tools at the top left.

Known limits

  • Publishing is not a separate mode. Export lives inside Check › Community Checking. See Export a book as PDF.
