Export a book as USFM (aligned or plain)

Shippedrc.1

Save the open book as a USFM file — with your word alignments woven in, or plain text only.

Where in the app: Check › Community Checking › Export › USFM, aligned or USFM, plain

What it is

USFM is the standard text format for Bible translations. tC4 can export the open book two ways:

  • USFM, aligned — your text with the word alignments to the original language included, the format other alignment-aware tools read.
  • USFM, plain — just your text, without alignment data.

The file is written outside the project. Your project does not change (apart from a checkpoint).

When to use it

To hand a book to another program, a typesetter, or a reviewer who works in USFM.

Step by step

  1. Open the book and click Check. If the last checking tool you used opens instead of the list, click ← All checking tools.
  2. Click Open → on the Community Checking card.
  3. Click Export.
  4. Click USFM, aligned or USFM, plain.
  5. A save window opens with a suggested file name. Keep it or type another, then save.
  6. When the file is saved, the panel shows "Saved <file name>", for example "Saved TIT-aligned-2026-10-05.usfm". If you cancel, no message appears.

What you should see

  • USFM, aligned saves a file named like TIT-aligned-2026-10-05.usfm.
  • USFM, plain saves a file named like TIT-2026-10-05.usfm.
  • The panel shows "Saved <file name>".

Screenshots

Tips

  • Align your verses first if you want the aligned file to carry alignments. See Link and unlink words.
  • Until you align, USFM, aligned and USFM, plain give the same text: there are no alignments to weave in yet.
  • Unlike the PDF, USFM export does not refuse a book with nothing drafted.
  • A verse span you joined is written as one verse, for example \v 2-3.
  • On Linux, the save window is the system file window. Its title bar shows a long "blob:http://127.0.0.1…" address; that is normal. It opens in your Downloads folder, with the suggested name selected in the Name field. On this build its Save and Cancel buttons were above the visible part of the window: press Enter to save, or Esc to cancel.

Known limits

  • On Windows the plain USFM export does not download in this build (issue #425).
  • Known issue: The book's header lines (\h, \toc1–\toc3, \mt) contain the book code (for example TIT), not the book's name. Edit them in the file if another program needs the name.
  • Known issue: Undrafted verses are written with a ___ placeholder.
