Export a project as a Scripture Burrito

Shippedrc.1

Save the whole project — text, alignments and checking decisions — as one Scripture Burrito zip. Works for Bible and Open Bible Stories projects.

Where in the app: Check › Community Checking › Export › Scripture Burrito (.zip)

What it is

A Scripture Burrito is the open, standard package format tC4 uses for every project. Exporting one gives you a single zip of the whole project: every book (or all fifty stories), your alignments and your checking decisions. tC4 can import it again as a new project.

When to use it

  • To keep a copy of the project somewhere safe.
  • To move the project to another computer and import it there (see Import a project).
  • To give the project to another Scripture Burrito tool.

Step by step

  1. Open the project and click Check. If the last checking tool you used opens instead of the list, click ← All checking tools.
  2. Click Open → on the Community Checking card.
  3. Click Export, then Scripture Burrito (.zip).
  4. A save window opens with a suggested file name. Keep it or type another, then save.
  5. When the file is saved, the panel shows "Saved <file name>", for example "Saved QA373 Titus-2026-10-05.zip". If you cancel, no message appears.

What you should see

  • A file named after the project and today's date, like QA373 Titus-2026-10-05.zip, is saved.
  • The panel shows "Saved <file name>".

Screenshots

Tips

  • Stories also offer this zip. Their Export menu lists Export PDF, Story Markdown (.zip), and Scripture Burrito (.zip). See Export stories as PDF or Markdown.
  • The zip holds every book of the project, not only the open book.
  • To bring the zip back into tC4, on this or another computer, use + Add a project › Import a project › Scripture Burrito. The review shows what carries over from tC4 (alignments and checking decisions). See Import a project.
  • On Linux, the save window is the system file window. Its title bar shows a long "blob:http://127.0.0.1…" address; that is normal. It opens in your Downloads folder, with the suggested name selected in the Name field. On this build its Save and Cancel buttons were above the visible part of the window: press Enter to save, or Esc to cancel.

Known limits

  • To put a project on Door43, use Share on Door43 on its Home card instead (see Share to Door43).
