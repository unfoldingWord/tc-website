What’s in translationCore® 4

translationCore® 4 is a new version of translationCore®. It brings drafting, checking, and alignment together with export, import, and sharing to Door43.

Draft for real

Draft a whole section at a time, then place verse numbers. Create verse spans, and add paragraph and poetry formatting as you go.

Original language beside you

See the Greek or Hebrew text beside the ULT and UST while you draft and check.

Helps and suggestions

Read with translation helps, leave comments, and get alignment suggestions as you align.

Open Bible Stories

Translate and check Open Bible Stories projects, then export story Markdown or a PDF.

Export and import

Export a book as aligned USFM, plain USFM, a Scripture Burrito zip, or a print-ready PDF. Start a project from a translationCore 3 zip, USFM files, or a Scripture Burrito.

Share to Door43, offline first

Share a project to Door43. The English resources ship in the download, so you can create, draft, check, and export with no internet.

Download

Choose your computer. Each button gets the newest build from GitHub.

Windows (64-bit) macOS (Apple silicon) Linux (64-bit)

Windows: the installer is signed. Run it and follow the steps.

Mac: download the .pkg installer. The Mac build is not signed yet, so macOS may block it the first time. Open System Settings > Privacy & Security and choose Open Anyway, or Control-click the installer and choose Open. It asks for an administrator password.

Linux: unpack the zip and run start-tc4.sh.
