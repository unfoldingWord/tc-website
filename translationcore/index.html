translationCore®

A focused desktop workspace for checking Bible translations against multiple sources and the original languages.

translationCore® (tC) is an open-source desktop platform that enables systematic and comprehensive checking of Bible translations. It integrates just-in-time training modules so your team stays aligned with best practices while they work.

Download View on GitHub

Available for Windows, macOS, and Linux

Built for translation checking

Every tool in translationCore® is designed to help translation teams produce accurate, clear, and natural Bible translations.

Figures of Speech

Open your project in the Translation Notes tool to check metaphors, similes, irony, and many other types of figures of speech. Contextual guidance drawn from historical, cultural, and linguistic scholarship.

Key Term Checking

Use the Translation Words tool to verify accuracy and consistency of key terms, names, and important words across the entire project.

Smart Alignment

AI-assisted alignment maps your translation to the original biblical languages. Visual alignment helps reviewers verify that every element of the source text is accounted for.

Gateway Language Support

translationCore® and its exegetical resources are available in the Gateway Languages of the world. Teams can access the full suite of checking tools in a language they understand.

Offline First

Install via the web or USB, then use all features with no internet connection. Ideal for teams working in remote or low-connectivity environments.

Progress Tracking

The tool tracks progress and provides a clear overview of which checks have been completed, enabling teams and consultants to manage quality assurance efficiently.

How it works

translationCore® brings together the unfoldingWord translation resources into a single checking environment.

  1. Open your project. Import or connect to a Bible translation project. translationCore® supports standard USFM format.
  2. Select a checking tool. Choose from Translation Notes (figures of speech), Translation Words (key terms), or Word Alignment.
  3. Work verse by verse. Review each check with contextual guidance from the integrated resources. Confirm or correct your work as you go.
  4. Track your progress. See which checks are complete, which need review, and where your team stands across the entire project.
  5. Export and share. When checking is complete, export your translation in standard formats ready for publication or further review.
